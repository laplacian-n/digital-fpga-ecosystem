============================================================
  FPGA Builder - คู่มือติดตั้งสำหรับนักศึกษา
  รองรับ 2 บอร์ด (เลือกในแท็บ 1):
   - Apex FPGA Surveyor-6 (Spartan-6 XC6SLX9)
       build ด้วย ISE ที่ bundle มาในโฟลเดอร์ (tools\ise_min ~2.7GB)
         - EDGE Spartan-7 (XC7S15)
       build ด้วย Vivado ที่ bundle มาในโฟลเดอร์ (tools\vivado_min ~15GB)
         ทั้ง 2 บอร์ดใช้ปุ่ม Program เดียวกัน (Normal Rom / PROM Rom)
============================================================

โปรแกรมนี้ใช้แปลงโค้ด VHDL เป็นไฟล์ .bit แล้วโหลดลงบอร์ด FPGA
(ทำหน้าที่แทนการกดปุ่มใน ISE/Vivado ให้ง่ายขึ้น)

ทุกอย่างอยู่ในโฟลเดอร์นี้โฟลเดอร์เดียว (ก๊อปทั้งโฟลเดอร์ไปใช้ที่เครื่องไหนก็ได้):
  FPGA_Builder.exe        <- โปรแกรมหลัก (ดับเบิลคลิกเปิด)
  setup.bat               <- รันครั้งเดียวหลังลง ISE (แก้ environment อัตโนมัติ)
  Xilinx.lic              <- license (setup.bat จะติดตั้งให้)
  อ่านก่อนใช้งาน.txt        <- ไฟล์นี้
  examples\               <- ตัวอย่าง VHDL
  tools\                  <- openFPGALoader, zadig, spiOverJtag (โหลดลงบอร์ด)
  source\                 <- ซอร์สโค้ด + rebuild_exe.bat (สำหรับผู้พัฒนา)
  build\                  <- โฟลเดอร์ผลลัพธ์ (โปรแกรมสร้างเองตอน Build)

------------------------------------------------------------
 สิ่งที่ต้องมี
------------------------------------------------------------
- Windows 10 หรือ 11 (64-bit)
- พื้นที่ว่าง ~18 GB (ISE + Vivado มาในชุดครบแล้ว)
  * ถ้าใช้แค่บอร์ด Spartan-6: ลบ tools\vivado_min ออกได้ เหลือ ~3 GB

------------------------------------------------------------
 ขั้นตอนติดตั้ง (ทำครั้งเดียว)
------------------------------------------------------------

[1] รัน setup.bat  (สำคัญที่สุด!)
    - ดับเบิลคลิก setup.bat ในโฟลเดอร์นี้
    - กด "Yes" เมื่อ Windows ถามสิทธิ์ Administrator
    - สคริปต์จะแก้ระบบให้อัตโนมัติ (ISE มาในชุดแล้ว ไม่ต้องลง):
        * ติดตั้ง VC++ 2008 runtime (ISE ต้องใช้)
        * แก้ network provider (กัน ISE tool ค้างตอนรัน)
        * เพิ่ม Windows Defender exclusion
    - รอจนขึ้น "SETUP COMPLETE!"

    หมายเหตุ: Spartan-6 พร้อม build เลยหลัง setup - ISE อยู่ใน
    tools\ise_min (~2.7GB) โปรแกรมหาเจอเอง license ก็มีให้แล้ว

[2] Vivado (Spartan-7) ก็มาในชุดแล้วเช่นกัน
    - อยู่ที่ tools\vivado_min โปรแกรมหาเจอเอง ไม่ต้องตั้งค่า
    - Vivado Standard ไม่ต้องใช้ license
    - หมายเหตุ: ห้ามย้าย/แก้โครงสร้างข้างใน tools\vivado_min
      (Vivado ไม่รองรับ shortcut/junction - ต้องเป็นโฟลเดอร์จริงเท่านั้น)

[3] เสียบบอร์ด (driver ลงอัตโนมัติจาก setup.bat แล้ว)
    - ต่อไฟเลี้ยงบอร์ด + เปิดสวิตช์ (ต้องมีไฟ LED ติด) แล้วเสียบสาย USB
    - setup.bat ติดตั้ง JTAG driver (WinUSB) ให้แล้ว - เสียบแล้วใช้ได้เลย
      ไม่ต้องทำ Zadig เอง (ทำครั้งเดียวใน setup พอ ใช้ได้กับทุกบอร์ด FT2232)

    ** เผื่อไว้ ** ถ้ากด Program แล้วขึ้น "unable to open ftdi device"
    (เกิดเฉพาะเครื่องที่เคยลง FTDI driver มาก่อน) ให้ทำ Zadig ครั้งเดียว:
    - รัน tools\zadig.exe -> Options -> List All Devices
    - เลือกตัวลงท้าย Dual RS232-HS สำหรับ Spartan-6 และ Digilent USB Device สำหรับ  Spartan-7 "(Interface 0)" -> driver = WinUSB -> Replace Driver
    - ทำครั้งเดียวต่อบอร์ด จำถาวร ไม่ต้องทำซ้ำ

------------------------------------------------------------
 การใช้งาน
------------------------------------------------------------

1. เปิด FPGA_Builder.exe

2. แท็บ "1. โปรเจกต์ & ชิป"
   - กด "เพิ่มไฟล์..." เลือกไฟล์ VHDL ของคุณ

3. แท็บ "2. กำหนด Pin"
   - กด "ดึงขาจาก VHDL" -> ได้รายชื่อ port มาให้
   - ดับเบิลคลิกช่อง Pin/LOC -> เลือกพินจาก dropdown
     (เช่น สวิตช์ = P66(SW0)..P55(SW7), ไฟ LED = P82(L0)..P67(L7))

4. กด "Build .bit"  ->  ได้ไฟล์ .bit ในโฟลเดอร์ build
   * โน้ตบุ๊ค: แนะนำ "เสียบสายชาร์จ" ตอน Build โดยเฉพาะบอร์ด Spartan-7
     (Windows อาจไม่ยอมรันงาน build ตอนใช้แบตเตอรี่ - ถ้า Build ค้าง/
      ขึ้น "Vivado ไม่เริ่มทำงาน" ให้เสียบชาร์จแล้วกด Build ใหม่)

   * เรื่องเวลา build (Spartan-7/Vivado): Vivado มี "ต้นทุนคงที่" ~40 วินาที
     ทุกครั้ง (เปิดโปรแกรม + synth + โหลดข้อมูลชิป + เขียน bitstream) ลดไม่ได้
     -> วงจรเล็ก ๆ ก็ใช้เวลา ~1 นาที "ทุกครั้ง" ไม่ใช่แค่ครั้งแรก (เป็นเรื่องปกติ)
     ครั้งแรกหลังเปิดเครื่องจะบวกอีก ~10-20 วิ (โหลดไฟล์จากดิสก์)

     ** ถ้า build นานเป็นนาที ๆ "ทุกครั้ง" (ผิดปกติ) เช็คตามนี้ (เรียงตามผลมากสุด): **
       1) เสียบสายชาร์จ! ใช้แบตเตอรี่ Windows หรี่ความเร็ว CPU -> synth ช้า 2-3 เท่า
          (นี่คือสาเหตุอันดับ 1 - Vivado synth ใช้ CPU หนัก)
       2) รัน setup.bat แล้วหรือยัง (เพิ่ม Windows Defender exclusion ให้) - ถ้าไม่มี
          Defender จะสแกน vivado.exe ทุกครั้งที่เปิด = ช้าทุกครั้ง. ถ้าย้ายโฟลเดอร์
          หลังรัน setup.bat แล้ว ให้รัน setup.bat ใหม่ที่ตำแหน่งใหม่
       3) วางโฟลเดอร์ไว้บน SSD ในเครื่อง อย่ารันจาก USB/harddisk ภายนอก (ช้ามาก)
       4) ปิดโปรแกรมที่กิน RAM (เบราว์เซอร์หลายแท็บ ฯลฯ) - RAM น้อยทำ cache หลุด
          ทุกครั้ง build เลยเป็น "cold" ตลอด
       5) ใช้แพ็กเกจเวอร์ชันล่าสุด (มี directive build เร็ว + ปิด webtalk)

5. โหลดลงบอร์ด: กด "Program (โหลดลงบอร์ด)"  (บอร์ดต้องเปิดไฟ)
   ถ้าขึ้น "unable to open ftdi" ให้กดปุ่ม "ตั้งไดรเวอร์ USB" ในโปรแกรม
   (ติดตั้งอัตโนมัติ) หรือทำ Zadig เอง (ดูขั้นตอน [3])
   จะมีให้เลือก 2 แบบ:
     1) Normal Rom (Fast - Temporary)
        โหลดเร็ว ลง SRAM - โปรแกรมหายเมื่อถอดปลั๊ก/ปิดไฟ (ใช้ตอนทดสอบ)
     2) PROM Rom (Slow - Permanent)
        เขียนลง Flash PROM (M25P80) - โปรแกรมอยู่ถาวรแม้ถอดปลั๊ก
        *คำเตือน: Flash เขียนซ้ำได้จำนวนจำกัด ให้ใช้อย่างคุ้มค่า
         ทดสอบด้วย Normal Rom จนวงจรเสร็จ แล้วค่อยเขียน PROM*

------------------------------------------------------------
 พินสำคัญบนบอร์ด (LVCMOS33 ทั้งหมด)
------------------------------------------------------------
 Slide Switch : SW0=P66 SW1=P62 SW2=P61 SW3=P59 SW4=P58 SW5=P57 SW6=P56 SW7=P55
 LED          : L0=P82 L1=P81 L2=P80 L3=P79 L4=P78 L5=P75 L6=P74 L7=P67
 Push Button  : PB1=P45 PB2=P46 PB3=P47 PB4=P48 PB5=P51
 DIP Switch   : DIP1=P112 ... DIP8=P99
 7-Segment    : a=P41 b=P40 c=P35 d=P34 e=P32 f=P29 g=P27
 Clock (OSC)  : P123 (20 MHz)

------------------------------------------------------------
 ปัญหาที่พบบ่อย
------------------------------------------------------------
- "Top module not found"  -> ตั้ง Top entity ให้ตรงชื่อ entity บนสุดในไฟล์
- โปรแกรม/xst ค้างไม่ขยับ  -> ยังไม่ได้รัน setup.bat (รันแล้ว restart เครื่อง)
- "unable to open ftdi"    -> ยังไม่ได้ทำ Zadig หรือบอร์ดไม่มีไฟ/สาย USB เสีย
                              (บางทีมี process ค้าง - ปิดแอปเปิดใหม่)
- โหลดไม่ได้ "device not found" -> เช็คไฟบอร์ด + สาย USB (ใช้สายที่ส่งข้อมูลได้)
- "ไม่พบ openFPGALoader" (ขึ้น path แปลก ๆ เช่น C:\msys64\... ที่เครื่องเราไม่มี)
    -> แปลว่าแตกไฟล์ zip ไม่ครบ ไฟล์ tools\openFPGALoader\openFPGALoader.exe หายไป
       (มักเกิดตอนแตกไฟล์ไว้ที่ path ยาว) ให้แตก zip ใหม่ด้วย 7-Zip ไว้ที่ C:\FPGA
       แล้วเปิดโปรแกรมใหม่ (โปรแกรมจะหาไฟล์ในชุดให้เองอัตโนมัติ)
- "Path too long" ตอนแตก zip/copy -> แตกไฟล์ไว้ที่ path สั้น ๆ เช่น
    C:\FPGA  (อย่าไว้ลึก เช่น Desktop\เอกสาร\...\ ที่ชื่อยาว)
    และใช้ 7-Zip แตก (จัดการ path ยาวได้ดีกว่า File Explorer)

- *** สำคัญ: ชื่อโฟลเดอร์ "ห้ามมีช่องว่าง" และห้ามภาษาไทย ***
    Vivado (บอร์ด Spartan-7) จะ build ล้มเหลวทันทีถ้า path มีช่องว่าง
      ผิด:  C:\FPGA Builder V6\   ,  C:\งานดิจิตอล\
      ถูก:  C:\FPGA_Builder_V6\   ,  C:\FPGA\
    (โปรแกรมจะเตือนให้ตอนเปิดถ้าชื่อโฟลเดอร์มีช่องว่าง)
