ภาควิชาวิศวกรรมคอมพิวเตอร์ คณะวิศวกรรมศาสตร์
สถาบันเทคโนโลยีพระจอมเกล้าเจ้าคุณทหารลาดกระบัง
การทดลองที่ 2 ออกแบบวงจร Combinational Logic
วัตถุประสงค์
1. เพื่อให้นักศึกษาเข้าใจขั้นตอนการออกแบบวงจร Combinational logic
2. เพื่อให้นักศึกษาเข้าใจขั้นตอนการแก้ปัญหาวงจรได้
การทดลอง
1. ให้นักศึกษาออกแบบพร้อมแสดงวิธีการออกแบบวงจรสร้างสัญญาณไฟเตือนข้ามถนน
ส าหรับทางข้ามถนนแห่งหนึ่งในบริเวณชุมชน เพื่อแสดงไฟข้ามถนนและไฟเตือนระมัดระวัง
1.1 ไฟข้ามถนนจะติดเมื่อมีเงื่อนไขครบทั้งหมดดังนี้
• เมื่อมีคนยืนอยู่
• ไม่มีรถยนต์บริเวณทางข้ามหรือสัญญาณไฟแดงติดอยู่
• ไม่มีรถฉุกเฉิน
1.2 ไฟเตือนระมัดระวังจะติดเมื่อมีเงื่อนไขครบทั้งหมดดังนี้
• มีคนสูงอายุหรือรถฉุกเฉิน
• สัญญาณไฟแดงติดอยู่หรือมีคนเดินเท้าและรถยนต์พร้อมกัน
โดยก าหนดให้เซนเซอร์แต่ละจุดส่งสัญญาณดิจิตอลมาดังนี้
• P = Pedestrian คือคนเดินเท้า จะเป็น 1 เมื่อมีคน และเป็น 0 เมื่อไม่มี
• C = Car คือรถยนต์ จะเป็น 1 เมื่อมีรถ และเป็น 0 เมื่อไม่มี
• R = Red Light คือสัญญาณไฟแดง จะเป็น 1 เมื่อไฟติดอยู่ และเป็น 0 เมื่อไม่ติด
• E = Emergency Vehicles คือรถฉุกเฉิน จะเป็น 1 เมื่อมีรถฉุกเฉิน และเป็น 0 เมื่อไม่มี
• S = Senior คือคนสูงอายุ จะเป็น 1 เมื่อมีคนสูงอายุ และเป็น 0 เมื่อไม่มี
และก าหนดให้รับอินพุท P C R E S ทางสวิตช์โยกบนเครื่อง Logic Trainer และต่อเอ้าท์พุทเข้ากับ
Logic Monitor ทั้ง 2 ดวงบน Logic trainer
